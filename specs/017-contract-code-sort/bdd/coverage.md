# BDD 场景覆盖矩阵

**Feature**: 017-contract-code-sort
**场景文件**: [contract-code-sort.feature](./contract-code-sort.feature)
**执行载体**: `tests/e2e-contract-code-sort.spec.js`（14 个 Playwright 用例，本地全绿）
**Date**: 2026-08-03

共 **8 个场景 + 4 个场景大纲**（合计 15 例）。项目无 Cucumber 工具链，`.feature` 用于场景评审，
实际执行由下表映射到 Playwright 用例。

> **本轮 BDD 的实际产出**：场景「排序键存在并列值时翻页仍不重复不遗漏」首次执行即**失败**，
> 暴露出一个既有缺陷（[#16](https://github.com/cuitaocrazy/newpm/issues/16)）——排序键并列时翻页
> 出现记录重复与等量遗漏，且 `contract_sign_date`（133 行并列）、`contract_amount`（107 行）
> 等**既有排序列**受影响更深。修复方式为排序时追加唯一次级键 `c.contract_id`，本次一并落地。

## 一、功能需求覆盖（FR-001 ~ FR-008）

| 需求 | 内容摘要 | 覆盖场景 | 执行用例 | 状态 |
|---|---|---|---|---|
| FR-001 | 合同管理列表可按合同编号排序 | 合同编号表头提供排序图标（例：合同管理） | `合同管理列表的合同编号表头可排序` | ✅ |
| FR-002 | 付款里程碑列表可按合同编号排序 | 合同编号表头提供排序图标（例：付款里程碑） | `付款里程碑列表的合同编号表头可排序` | ✅ |
| FR-003 | 升序 → 降序 → 取消 三态循环 | 点击表头按三态循环切换（2 例） | 同上两个用例内的三次点击断言 | ✅ 2 例 |
| FR-004 | 后端全局排序而非当页重排 | 排序作用于全部数据而非当前页 / 升序与降序给出相反排列 | `排序是后端全局排序：第一页与第二页记录互不重复`、`合同列表按 contract_code 升序 / 降序返回不同结果`、`付款里程碑列表按 contract_code 排序且不拆散合同分组` | ✅ 3 个 |
| FR-005 | 取消排序回到默认排序 | 点击表头按三态循环切换（第三次点击） | 表头 class 不含 ascending/descending 的断言 | ✅ |
| FR-006 | 排序与查询条件叠加 | 排序与查询条件叠加生效 | `排序与筛选条件叠加：筛选范围与总数不因排序改变` | ✅ |
| FR-007 | 翻页保持排序 | 翻页时保持当前排序 | `合同管理列表翻页后仍保持排序` | ✅ |
| FR-008 | 空编号参与排序不被丢弃 | 合同编号为空的记录参与排序而不被丢弃 | `空合同编号在升序时排最前且仍出现在列表中` | ✅ |

## 二、不变式覆盖（INV-1 ~ INV-4）

| 不变式 | 内容 | 覆盖场景 | 执行用例 | 状态 |
|---|---|---|---|---|
| INV-1 | 排序不拆散合同的付款分组 | 排序不拆散同一合同的多条付款里程碑 | `付款里程碑列表按 contract_code 排序且不拆散合同分组`（断言 `contractId` 无重复） | ✅ |

| INV-4 | 分页与排序叠加不重复不遗漏 | 排序键存在并列值时翻页仍不重复不遗漏（3 例） | `排序是后端全局排序…`、`按 contract_sign_date / contract_amount / project_budget_total 排序时翻页不重复不遗漏` | ✅ 4 个（**修复 #16 后转绿**） |

## 四、未覆盖与已知边界

| 项 | 状态 | 说明 |
|---|---|---|
| 付款里程碑同一合同跨页出现 | **不视为缺陷，未写断言** | 该查询按数据库行分页，合同的多条付款跨页边界必被切开。已验证不带排序参数时同样发生，与排序无关 |
| 「重置」按钮不清除排序 | **有意保留，未写断言** | `resetQuery` 走 `resetForm("queryRef")`，只重置表单绑定字段；此行为与合同页排序上线以来一致，见 spec.md §五 |
| 前端 `handleSortChange` 的单元测试 | **未覆盖** | `ruoyi-ui` 无单测地基（无 vitest/jest），已单独记录为 [#15](https://github.com/cuitaocrazy/newpm/issues/15) |
